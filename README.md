# 📦 Gestión de Órdenes

App Android para administrar **clientes, productos y órdenes de venta** con base de datos local.

## Funcionalidades
- Registro y edición de **clientes** y **productos**
- Creación de **órdenes** con su **detalle** (productos y cantidades)
- Consulta del detalle de cada orden
- Persistencia local con **SQLite** (tablas `Clientes`, `Productos`, `Ordenes`, `DetalleOrden`)

## Tecnologías
`Kotlin` · `Android Studio` · `SQLite (SQLiteOpenHelper)` · `Gradle Kotlin DSL`

## Cómo ejecutar
1. Abrir la carpeta en **Android Studio** (File → Open).
2. Esperar el Gradle Sync.
3. Ejecutar en un emulador o dispositivo con **Run ▶**.
